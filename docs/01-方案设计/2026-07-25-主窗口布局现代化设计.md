# DeviceForge 主窗口布局现代化重设计

**日期**：2026-07-25
**状态**：已完成（v2.4）
**关联**：[[2026-07-25-FTP双栏重构设计]]

---

## 背景

FTP 双栏重构后，FTP Tab 内已自备完整的远程文件浏览能力。右侧远端预览面板的核心功能与 FTP Tab 重叠，继续保留会造成用户困惑。同时，当前布局为传统 Qt 三段式（顶部设备栏 + QSplitter 水平分割 + 底部日志），视觉风格偏旧。

本次重设计两个目标：
1. **移除远端预览面板**，消除功能冗余
2. **现代化整体布局**，为开源推广提供更有说服力的第一印象

## 设计方向

**左侧竖排图标导航栏**替代顶部水平 QTabWidget。这是现代桌面应用（VS Code、Postman、Figma）最通用的导航模式，提供即时的"现代感"感知。

## 三、设备栏

### 重构为紧凑胶囊式

```
┌──────────────────────────────────────────────────────────┐
│ 📡 [192.168.1.100  ×] [192.168.1.101  ×] [+ 添加设备]   │
│ 👤 admin     🔑 ********              [FTPS] [连接 ▾]   │
└──────────────────────────────────────────────────────────┘
```

| 元素 | 样式 |
|------|------|
| 设备标签 | 石墨底 #232A36，圆角 4px，琴色边框仅选中态 |
| × 删除按钮 | Hover 时显示，琴色 #E85848 |
| + 添加设备 | 虚线边框 #333B48，Hover 时实线 #7B8494 |
| 整体高度 | 约 64px（两行），比当前更紧凑 |

### 与 DeviceBusWidget 的关系

当前 DeviceBusWidget 是一个独立的 QWidget。重构后：
- DeviceBusWidget 的**数据逻辑保留**（设备列表、凭证、信号）
- **UI 渲染重写**为胶囊式 compact 布局
- 嵌入到内容区顶部，不再是独立的厚重横条

## 四、工具工作区

内容区：QVBoxLayout 从上到下依次为：
1. 设备栏（compact，~64px）
2. Tool 内容（QStackedWidget，占满剩余空间）
3. 日志（可折叠）

QStackedWidget 替代 QTabWidget：
- `ui.tabWidget`（QTabWidget）→ `m_toolStack`（QStackedWidget）
- 左侧导航栏点击切换 `m_toolStack->setCurrentIndex()`
- 每个 Tool 的 Widget 创建方式不变（Backend + Widget 配对）

## 五、底部日志

### 折叠态（默认）

- 高度：4px 细条
- 颜色：#252A33
- 新日志到达时：琴色微光闪烁 600ms（QPropertyAnimation + color）

### 展开态

- 高度：~150px（约 20% 窗口高度）
- 顶部标题栏：`📋 全局日志` + `[▲ 折叠]` 按钮
- 日志内容区：QTextEdit，只读，等宽字体 Consolas 11pt
- 折叠按钮交互：点击 → QPropertyAnimation 收起到底部

### 交互

| 操作 | 行为 |
|------|------|
| 点击折叠条 | 展开日志面板 |
| 点击折叠按钮 ▲ | 折叠日志面板 |
| 新日志 + 折叠态 | 折叠条闪烁琴色 |
| 清空日志 | 按钮在标题栏右侧 |
