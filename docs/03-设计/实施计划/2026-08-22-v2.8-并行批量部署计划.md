# DeviceForge v2.8 并行批量部署实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 部署循环并发化（并发度可配 1-8，默认 1）+ 每设备实时进度/状态 + 部署报告 CSV/HTML 导出 + 失败设备一键重试。

**Architecture:** 将 `FtpDeployBackend::startUpload` 内的串行 for 循环拆为 `DeployJob`（QRunnable，单台设备完整事务，持独立 adapter 与独立取消标志）+ `DeploymentRunner`（私有 QThreadPool 限流调度、聚合约并、对外回调签名不变）。新增纯逻辑 `DeviceResult/DeployReport/renderCsv/renderHtml` 承接 TDD 主战场。

**Tech Stack:** Qt 6 (Core/Test/Concurrent)、libcurl/libssh2（经 IProtocolAdapter，接口零改动）、QtTest、CMake+CTest。

**Spec:** `docs/03-设计/方案设计/2026-08-22-v2.8-并行批量部署设计.md`（含 §11 决议记录，与本计划同读）

## Global Constraints

- 全中文注释与文档；专有名词除外（开发规范第 1 条）
- TDD 红-绿-重构强制；每任务独立提交；分支 `feature/v28-*` 从 main 新建，`--no-ff` 合回
- CI 是 Qt 6.9.2（本地 6.11.1）：不得使用仅新版才有的 API
- 出厂默认并发度 = **1**；设置范围 1-8；ConfigStore 键 `deploy.concurrency`
- `IDeployable` / `IProtocolAdapter` 接口零改动（ABI 安全）
- 日志脱敏纪律不变；UI 回调一律 QueuedConnection 编组（沿用 connectBackendSignals 管道）
- 新测试目标注册遵循 `tests/AGENTS.md` 模板，`ENVIRONMENT_MODIFICATION PATH=path_list_prepend` 必须保留
- 异步回调防 UAF：Backend 析构/OnStop 必须 cancel-all + wait 后才放行
