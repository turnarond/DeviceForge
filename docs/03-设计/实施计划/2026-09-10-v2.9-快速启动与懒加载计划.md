# v2.9 快速启动与懒加载实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 先显示可响应的主窗口外壳，再按需加载文件与专业工作区，并建立可重复的启动性能基线。

**Architecture:** 用 StartupTracer 度量 Bootstrap/First Frame/Deferred Ready；WorkspaceLoader 以显式状态机保证每个工作区只创建一次、失败可重试。QWidget 始终在 GUI 线程创建，连接、目录读取和协议初始化在首帧后执行。

**Tech Stack:** C++17、Qt Widgets/Core/Test、ConfigStore、curl/libssh2/open62541

**Spec:** `docs/03-设计/方案设计/2026-09-09-v2.9-快速启动与懒加载设计.md`

## Global Constraints

- 保持 LogBridge→ProtocolRegistry→主题→窗口的安全依赖顺序，但把非必需工作延后。
- 首帧前应用必要主题，不允许无样式闪烁。
- QWidget 只能在 GUI 线程构造；未加载 Tool 不启动线程或 socket。
- 首窗可见时间相对 v2.8 基线至少降低 50%；热启动中位数优先低于 500 ms。
- 本计划在工作区注册表接口稳定后执行。
