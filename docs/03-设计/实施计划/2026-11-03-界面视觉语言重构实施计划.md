# 界面视觉语言重构（Instrument 精密仪器）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 DeviceForge 双主题 QSS 全量重写为「Instrument 精密仪器」视觉语言（冷灰白 + 深青信号），并把约 45 处代码内嵌色值迁移到双主题 token 单源，不改变任何布局与功能。

**Architecture:** 先建 `src/app/ThemeTokens.h` 作为双主题色值单源（纯头 + 取色函数），再以「旧色值静态守卫」驱动代码替换；两份 QSS 按现有选择器节逐节重写（只换色值/边框/圆角/字号，不删规则）；测试用像素断言锁定目标 token，用守卫测试锁定残留清零。

**Tech Stack:** Qt 6.11.1（CI 6.9.2）、C++17、QSS、QtTest/CTest、Python 3（devtools 工具集）

**Spec:** `docs/03-设计/方案设计/2026-11-02-界面视觉语言重构设计.md`（本计划从该设计出发；执行者两个文件都要读）

## Global Constraints

- **QSS 能力边界**：无 `box-shadow`、无渐变（除 `qlineargradient`/`qradialgradient`）、无 `line-height`、无逐列选择器；层次只用纯色明度阶梯 + 1px 线
- **不删现有 QSS 规则**：两份 QSS 各约 868 行，重写=逐节替换值，选择器集合不得减少（漏节会导致控件回退 Qt 默认样式）
- **基础字号 9pt 保留**；表格行高保持 22px（QSS 被代码覆盖，见设计 §2 降级清单）
- **双主题语义一致**：同一状态在浅色/深色下含义相同；accent 只用于动作/活跃（「青色是动词」）
- **默认主题不变**（ConfigStore `appearance.theme` 默认仍 dark）；主题切换即时刷新不在本波范围
- **不新增第三方依赖**；CI 用 Qt 6.9.2，QSS 语法不得用仅 6.11 特性
- **旧色值清零**：`#F0A030` `#D48820` `#F0B840` `#40C8A0` `#2FA88A` `#E85848` `#D6453A` `#7B8494` `#6B7480` `#C8CCD4` `#0B0E14` `#141820` `#0E1219` `#232A36` `#252A33` `#333B48` `#3A4250` `#1A1200` 在 src/ 的 .qss 与 .cpp/.h 中全部消失（新 token 值不同）

## Review Focus

以下 5 类输入/条件，设计未逐条写测试但最可能伤到使用者（先列，测试已挂到对应任务）：

1. **控件选择器漏覆盖**：浅色主题下任何漏节控件会回退 Qt 默认白底黑字/系统蓝色，且与青系不协调——Task 3/4 的像素测试 + Task 7 巡检钉住
2. **伪态未覆盖**：`:focus`/`:hover`/`:pressed`/`:disabled`/`:selected`/`:checked` 缺失会让输入框、按钮、选中行在交互瞬间「破功」——Task 3/4 断言覆盖关键伪态
3. **表格行高/列宽被代码覆盖**：QSS 的 padding 被 `setDefaultSectionSize(22)` 与列宽设置盖掉——Task 7 用 `tst_deploy_toolbar_layout` 等布局测试回归
4. **主题切换后内嵌色不刷新**：状态点/模型前景在重建时才刷新（与现状一致），用户切主题后旧色残留是预期行为——Task 4 验证里显式确认并记录，不当作缺陷
5. **运行时内嵌色值漏换**：`setStyleSheet`/`setForeground` 等运行期设色（状态点、模型、富文本链接）——Task 5 的 `theme_guard.py` 绿 + 全仓 grep 钉住

```cpp
#include <QtTest/QtTest>
#include <QColor>
#include "app/ThemeTokens.h"

class TstThemeTokens : public QObject {
    Q_OBJECT
private slots:
    void lightCanvasIsColdGrey()      { QCOMPARE(tokens::color(tokens::Token::Canvas, false), QColor("#E9EDF0")); }
    void lightAccentIsDeepTeal()      { QCOMPARE(tokens::color(tokens::Token::Accent, false), QColor("#0E766E")); }
    void darkAccentIsBrightTeal()     { QCOMPARE(tokens::color(tokens::Token::Accent, true),  QColor("#2DD4BF")); }
    void darkPanelIsGreyBlue()        { QCOMPARE(tokens::color(tokens::Token::Panel, true),   QColor("#141B24")); }
    void warningExistsInBothThemes()  { QVERIFY(tokens::color(tokens::Token::Warning, false).isValid());
                                        QVERIFY(tokens::color(tokens::Token::Warning, true).isValid()); }
    void allTokensResolveInBothThemes() {
        for (int i = 0; i <= int(tokens::Token::Warning); ++i) {
            QVERIFY2(tokens::color(tokens::Token(i), false).isValid(), "light token invalid");
            QVERIFY2(tokens::color(tokens::Token(i), true).isValid(),  "dark token invalid");
        }
    }
};
QTEST_MAIN(TstThemeTokens)
```
