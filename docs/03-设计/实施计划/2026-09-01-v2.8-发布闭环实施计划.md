# DeviceForge v2.8 发布闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为已发布的 v2.8.0 恢复可执行的 CI/发布验收门禁，消除版本与 SDD 文档漂移，并形成不伪造结果的验收报告。

**Architecture:** 以 `CMakeLists.txt` 的版本为唯一权威，由 Python 工具对所有发布事实源做强校验；日常 CI 负责 Debug/Release 与工具测试，手动工作流负责 Release、GUI 冒烟和 NSIS 产物。运行时代码和公开接口保持不变，所有尚未执行的现场或长稳项目在验收报告中保持未完成。

**Tech Stack:** Qt 6.9.2/6.11.1、C++17、CMake 3.22+、CTest、Python 3、GitHub Actions、PowerShell、NSIS 3.x

**Spec:** `docs/03-设计/方案设计/2026-09-01-v2.8-发布闭环设计.md`

## Global Constraints

- 只修改发布治理、构建入口、测试工具和文档；不修改 `src/` 运行时代码或公开 C++ 接口。
- `CMakeLists.txt` 中 `project(DeviceForge VERSION 2.8.0 ...)` 是唯一权威版本；不移动、不覆盖 `v2.8.0` Tag。
- 日常 CI 使用 Windows、Qt 6.9.2、Python 3.12，并分别验证 Debug/Release。
- 本地开发基线为 Qt 6.11.1；Qt 安装路径可配置，示例为 `D:\Qt\6.11.1\msvc2022_64`，不得把 `C:\Qt` 当成唯一安装位置。
- 严格执行 TDD 红—绿—重构；每个任务单独提交，文档和行为变更在同一任务内同步。
- GUI 冒烟、NSIS、CI 首次远端执行、16 台 50 轮长稳若没有新日志或产物，必须明确记为“未执行”或“阻塞”。
- Windows DPAPI 测试必须在具有正常用户配置文件的账户上下文执行；隔离账户错误 2/3 不得误判为产品缺陷。
- GitHub Actions 仅授予 `contents: read`，发布验收只上传 artifact，不创建 Release、不写 Tag。

```python
def extract_release_notes(path: Path) -> Optional[str]:
    if not path.is_file():
        return None
    m = re.search(r"^#\s+DeviceForge\s+v(\d+\.\d+\.\d+)\s+Release Notes\s*$",
                  _read(path), re.MULTILINE)
    return m.group(1) if m else None


def extract_roadmap(path: Path) -> Optional[str]:
    if not path.is_file():
        return None
    m = re.search(r"\*\*当前版本\*\*：v?(\d+\.\d+\.\d+)", _read(path))
    return m.group(1) if m else None
```

把以下来源加入 `DEFAULT_SOURCES`：

```python
("release_notes", "RELEASE_NOTES.md", extract_release_notes, False),
("roadmap", "ROADMAP.md", extract_roadmap, False),
("产品路线图", "docs/01-白皮书/产品路线图.md", extract_roadmap, False),
```

最终返回改为：

```python
return CheckResult(reports, authority,
                   not mismatches and not missing,
                   mismatches, missing)
```

CLI 失败信息同时输出 `mismatches` 与 `missing`，删除“缺失不阻断”的 warning 分支。

```yaml
  push:

    branches: [main]

  contents: read
jobs:
  python:

    steps:

      - uses: jurplel/install-qt-action@v4
        with:
```
