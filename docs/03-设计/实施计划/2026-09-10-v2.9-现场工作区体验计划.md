# v2.9 现场工作区体验实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把主窗口改造成固定设备上下文、文件默认工作面和按需专业工作区，并提供稳定的 Tool 内传输任务抽屉。

**Architecture:** 主窗口拥有不可变 WorkspaceContext 和工作区容器；工作区各自保存展示状态，运行任务绑定创建时设备快照。File 工作区复用既有双栏并通过 TransferScheduler 订阅任务事件。

**Tech Stack:** C++17、Qt Widgets、QtTest、既有 NavBar/DeviceBusWidget/FileBrowserPanel

**Spec:** `docs/03-设计/方案设计/2026-09-09-v2.9-现场工作区体验设计.md`

## Global Constraints

- 琴色仅用于活跃/选中/主操作信号态，进度色为 `#40C8A0`。
- 状态必须同时有文字或图标，不能只靠颜色。
- 输入框获得焦点时不得抢占方向键；CI 兼容 Qt 6.9.2。
- 工作区切换不取消任务；运行任务不随顶部设备选择漂移。
- 本计划依赖传输可靠性内核计划完成并通过评审。
