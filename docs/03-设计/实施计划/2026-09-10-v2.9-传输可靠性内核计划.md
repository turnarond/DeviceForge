# v2.9 传输可靠性内核实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让双栏上传、双栏下载和批量部署共享异步、重试、取消、文件级恢复与原子交付语义。

**Architecture:** 新增 `src/transfer/` 领域层，以不可变 TransferTask 驱动按设备串行、跨设备并行的 Scheduler；Executor 通过内部 ITransferChannel 包装既有 FTP/SFTP Adapter。批量部署保留设备事务语义，只委托内核完成文件交付。

**Tech Stack:** C++17、Qt 6.9.2+ Core/Concurrent/Network/Test、libcurl、libssh2、QtTest/CTest

**Spec:** `docs/03-设计/方案设计/2026-09-09-v2.9-传输可靠性内核设计.md`

## Global Constraints

- 保持 `IProtocolAdapter`、`IDeployable` ABI；不新增纯虚函数。
- 所有网络 I/O 离开 GUI 线程；进度最多每 100 ms 发布一次，终态立即发布。
- 同设备键（协议+主机+端口+用户）严格 FIFO，不同设备并发度 1–8。
- 自动重试仅针对瞬时故障，退避 1 秒、3 秒，总尝试次数最多 3。
- 密码不进入 TransferTask；任务结束调用 `AuthInfo::clear()`。
- Qt API 必须兼容 CI 的 Qt 6.9.2；日志不得记录凭证或原始报文。
