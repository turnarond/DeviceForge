| **SFTP 文件管理** | SshAdapter SFTP 子系统（列目录/上传/下载/删除/重命名/新建目录），双栏 FTP/SFTP 协议切换 | v2.5 |

| **WebSocket 通信** | Server/Client 双模式，默认 127.0.0.1 绑定 + 可选 Token 认证 | v2.0 |
| **Modbus 集群测试** | QModbusTcpClient 批量读写寄存器，QTimer 自动刷新 | v2.0 |
| **网络调试中继** | TCP/UDP/组播透明中继代理，双向流量捕获 + Hex 实时视图 | v2.1.0 |
| **网络调试录制回放** | `.nrec` 自定义二进制格式录制 + 按原始时序回放，组播零影响加入抄收 | v2.1.0 |
| **OPC UA 客户端** | open62541 v1.5.5，读/写/订阅/浏览，None 安全策略 + 匿名认证；地址空间浏览 5 列 UI + 类型友好名 + 节点类色块 + × 删除按钮；针对非规范服务端的 ActivateSession policyId 深拷贝补丁；订阅卡死修复（请求超时 + 后台线程 + 移除冗余轮询） | v2.2.0 / v2.3.0 |
| **在线更新 (OTA)** | GitHub Releases API 查询 + zip 下载 + 校验 + 解压 + Updater.exe 独立替换进程 | v2.2.0 |
| **远端预览面板** | 🗑 已移除（v2.4 FTP 双栏替代，原 v2.2.0 实现） | v2.2.0 |
| **构建系统** | CMake 标准构建（qt_standard_project_setup），Debug/Release/RelWithDebInfo，/FS PDB 共享 | v2.2.0 |
| **UI 主题** | 「琴色是动词」工业深色主题，QSS 体系，全控件统一 | v2.0 |
| **本地配置持久化（ConfigStore）** | SQLite 单表 + Windows DPAPI 密码加密；设备/OPC UA endpoint/Modbus 从站/NetRelay/WebSocket/Telnet 偏好 + FTP 凭证全部自动恢复；统一设置面板（Ctrl+,）查看/导入/导出 | v2.3.0 |
| **并行批量部署** | 并发度 1–8、逐设备实时进度、CSV/HTML 报告、失败设备重试、取消终态 | v2.8 |
| **传输可靠性内核** | 双栏上传/下载、本地复制/移动与批量部署统一 TransferScheduler→TransferExecutor→ITransferChannel：瞬时错误重试、SHA-256 校验、临时文件原子提交、项目级取消、已交付文件恢复跳过 | v2.9 |
| **批量命令与重启闭环** | BatchCommandRunner 统一 Telnet/SSH 命令下发（顺序/超时/重试/取消）；部署后仅对成功设备重启，重启断开连接识别为预期成功 | v2.10 |
| **设备任务中心** | 统一设备档案 `src/device/`（DeviceProfile/DeviceRegistry：多协议端点 + ConfigStore device.profile 持久化 + 旧 device.list 兼容迁移、删除持久）；任务层 `src/task/`：TaskTemplateStore（版本化模板、凭据拒绝入库）、TaskExecutionEngine（部署→命令→重启→恢复编排、设备串行、retryFailed 阶段恢复：已交付文件不重传/成功设备跳过）、TaskRunStore（task.run/.device/.step 三级记录、设备名称/地址不可变快照、筛选/保留清理/脱敏）、TaskCenterWidget（三栏任务中心页、风险确认默认拒绝、失败重试与任务运行 CSV/HTML 报告导出）；设备总线胶囊名称优先 + 端点悬浮详情 + 双击档案编辑 | v2.11 |

## 短期规划（v2.9 → v2.11 已交付）

**v2.8（2026-08-22）已交付 —— 并行批量部署**：并发度可配（1–8）、逐设备实时进度、CSV/HTML 部署报告、失败设备一键重试与 NSIS 安装包。

**v2.9（2026-09-16，补丁 09-26）已交付 —— 传输可靠性内核**：双栏与批量部署统一重试/校验/原子提交/取消/失败恢复；v2.9.1 修复 FTP QUOTE 响应写入失败与瞬时提交错误重连。

**v2.10（2026-09-29）已交付 —— 批量命令与重启闭环**：BatchCommandRunner 统一命令下发（Telnet/SSH、超时、重试、取消），部署后仅对成功设备重启并识别重启断开为预期成功。

**v2.11（2026-10-08）已交付 —— 设备任务中心**：统一设备档案（DeviceRegistry）、任务模板库（TaskTemplateStore）、编排执行引擎（TaskExecutionEngine，含失败阶段恢复）、执行记录持久化（TaskRunStore）与三栏任务中心页（TaskCenterWidget）；端到端验收由 `tst_task_center_e2e` 覆盖（圈选→部署→命令→重启→恢复→持久化→重试）。

| 项目 | 优先级 | 说明 |
|------|--------|------|
| **快速启动与懒加载** | 🟡 验收中 | 首窗优先、Tool 首次访问加载（任务中心页已实现懒建）；待补启动耗时基线 |

## 中期规划 (v2.12+)

| 项目 | 优先级 | 说明 |
|------|--------|------|
| **NetRelay 非阻塞增强** | 中 | 非回环绑定模态确认弹窗、背压节流（setReadBufferSize）、客户端来源 allowlist |
| **ToolHost 多 Tool 并发** | 中 | 当前 DeployMaster 直接创建 Tool，待 ToolHost 支持多 Tool 并行管理 |
| **插件化加载 (QPluginLoader)** | 中 | DLL 动态加载 .dll Tool 插件，manifest.xml 入口点 |
| **跨平台 GUI** | 中 | Linux (X11/Wayland) 原生运行，DpapiCrypto 需替换为 libsecret |
| **SCP 部署上传** | 中 | 复用 v2.9 传输内核，提供无目录列表的部署上传通道 |

## 长期愿景

| 方向 | 说明 |
|------|------|
| **工业级系统部署调试平台** | 覆盖各类工业设备的部署 → 测试 → 运维全流程，成为工业工程师的通用工具箱 |
| **社区生态** | 插件市场、模板分享、第三方 Tool 贡献机制 |

> 注：OPC UA 安全策略（Basic256/证书）、多语言国际化暂不作为优先方向，视社区反馈再定。
