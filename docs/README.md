## 一致性约定

1. **引用新路径**：活文档（00/01/02/04/05 目录）必须引用当前有效路径，禁止引用 `docs/superpowers/` 等已废弃路径。
2. **历史归档**：`03-设计/` 下历史方案/计划文档为过程记录，其内部旧路径引用视为历史快照、不再维护。
3. **版本号同步**：改版本号按 `01-白皮书/版本发布与Tag规范.md` 全仓同步，并用 `tools/devtools/versioncheck.py` 校验。
4. **禁止双轨**：发现重复/英文残留/失效引用，按开发规范第 2 条立即合并清理。
5. **新文档**：中文命名 + 数字前缀排序，按 `2026-08-21-<主题>.md` 放入对应目录。
