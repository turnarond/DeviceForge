# DeviceForge 用户手册

## 快速入门

1. 从 [Releases](../../releases) 下载 `DeviceForge-v2.7.0-win64.zip`
2. 解压到任意目录
3. 运行 `DeviceForge.exe`

> 需要 [VC++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)（已安装 VS2022 可跳过）

├──────┬─────────────────────────┤

│ ...   │                         │

> v2.11.1：底部**综合日志输出**面板常驻一条折叠条（▾/▸），单击即可折叠/展开；折叠状态与展开高度自动记忆，下次启动保持。工具区与日志区之间仍可拖动分隔条调整比例。

### 外观设置

打开「文件 → 设置...」（或左侧导航栏 ⚙ 图标），设置面板顶部为「外观」下拉框：

- **暗色**（默认）：工业仪表盘深色主题
- **亮色**：浅色主题，「琴色是动词」语义不变——琴色等信号色自动加深以保证浅底可读性

切换即时生效，无需重启；选择自动保存，下次启动保持上次的主题。

设置面板「外观」下方为「**部署并发度**」滑块（范围 1-8，缺省 1）：控制文件部署/SFTP 批量部署的最大并行设备数。嵌入式设备的 FTP 服务器通常有最大连接数限制，建议设为 2-4；调整后点击「关闭」（确认并保存）写回配置，下一次部署即按新并发度执行。

## 功能模块

### 设备总线与设备档案（v2.11）

顶部胶囊栏每台设备为一个**档案**：名称优先展示，悬浮查看协议端点与备注，**双击打开档案编辑对话框**。v2.11.1 起端点表内：

- **协议**列为下拉选择（ftp / ftps / sftp / ssh / telnet / modbus；留空自动回退 ftp），不再需要手打。
- **凭据引用**列为下拉：可选择已有凭据记录，或选择「＋ 新建凭据…」就地填写用户名/密码——密码经 Windows DPAPI 加密后存入本地配置库（`ftp.credential`），档案与日志中只出现引用键，绝不落明文。
- **保存同键校验**：新增与编辑保存时，若某端点与其他档案的同协议端点完全同键（协议 + IP + 端口一致，按大小写/空格/默认端口归一化后比对），弹出确认框逐条列出冲突明细（**默认「否」**）——可保存但需确认；选「否」回到对话框继续修改，编辑内容不丢。同地址不同协议（如 ftp:21 与 sftp:21）不提示；历史已存档案不受影响、不追溯告警。

未接入档案的旧设备列表仍自动兼容读取；改名/改地址/删除设备不会在下次启动时"复活"旧记录。

### 设备任务中心（v2.11）

任务中心页把"对哪些设备、按什么顺序做哪些步骤"固化为**模板**，一键重复执行。三栏布局：

- **左栏 · 任务模板**：顶部小工具条「**新建模板**」（恒可用）与「**删除模板**」（选中启用）；搜索框按 名称/ID/标签 子串即时过滤；列表点击选中模板，**双击行=编辑该模板**（与「编辑模板」按钮同流）。
- **中栏 · 步骤与执行参数**：只读展示所选模板的摘要与步骤表（步骤｜类型｜参数摘要），摘要行下方为「**编辑模板**」按钮（选中启用）。步骤类型四种：**文件部署 / 批量命令 / 重启 / 恢复检查**，按模板内顺序编排执行。
- **右栏 · 设备 · 执行 · 历史**：目标设备预览（执行期按模板引用的设备档案 ID + 标签圈选解析，任一标签命中即纳入、同一设备不重复）；执行状态（总进度条 + 逐设备状态行）；最近执行历史表（开始时间｜模板｜状态｜设备）；操作按钮行——执行任务 / 取消 / 从失败阶段重试 / 导出报告 / 复制为新模板 / 导出模板 / 导入模板（各按钮按状态启用：执行需选中模板且有可用目标且无在跑轮次，取消仅在跑动中可用，重试/导出报告随所选历史记录可用性变化）。

**执行闭环**：点「执行任务」先弹摘要与风险确认（含重启等危险动作时**默认按钮「否」**，需主动确认才启动）；执行中可「取消」；每轮执行都落**不可变历史记录**（设备名称/地址为当时快照）。失败轮选中历史行后点「从失败阶段重试」：已交付文件不重传、已成功设备跳过，从失败阶段继续。选中历史记录可「导出报告」，保存对话框中按扩展名输出 CSV 或 HTML。

**历史管理**：应用启动自动对账——上次崩溃遗留的"执行中"记录收口为失败（中断）；随后按保留策略清理超期终态记录（默认 90 天，ConfigStore 项 `task/retention.days` 可覆盖；正在运行的记录永不删除）。

**凭据语义**：模板与档案只存凭据**引用**，密码由本机 DPAPI 配置库管理、不可跨机携带。执行按"设备档案"粒度取凭据——同一档案多个协议端点带不同引用时，本轮使用首个可解析引用并发中文提示（其余端点共用）。

**模板从哪来**：产品内五种正规途径——① **新建模板**（v2.13）：左栏「新建模板」打开编辑器对话框，填写元信息、勾选目标设备、编排步骤后保存，落库时自动生成独立模板 ID；② **编辑模板**（v2.13）：选中后点中栏「编辑模板」或双击左栏行，编辑器以该模板为初值打开，保存原位覆盖、ID 不变；③ 「复制为新模板」：以选中模板为底本，默认新名"原名 副本"，新模板独立 ID、版本号从 1 起；④ v2.13 的「导入模板」文件通道（见下）；⑤ **部署页「保存为模板」**（v2.14 #49-2）：「文件部署」页工具栏把当前单次部署配置一键捕获为预填模板，经同一编辑器对话框确认后落库（见「文件部署 · 保存为模板」）。

**模板编辑器**（v2.13，新建/编辑共用同一对话框）字段口径：

- **元信息**：名称（必填）、描述、标签（逗号分隔，执行期按标签圈选设备）、版本号（≥1 的整数，上限随存储 Int 域，编辑器不再设 999 死限；**手动编辑，编辑器不自动 +1**；同 ID 保存时低于已存版本的降级写入会被存储层拒绝）。
- **目标设备**：可勾选列表 = 本机设备档案 ∪ 模板已引用设备的并集；模板引用了本机不存在档案的设备**保留展示**（行尾标注「本机无档案」）且**默认可勾选**，保存时不剥离——建好同端点档案后自动接上（与导入的悬空引用口径一致）。
- **步骤列表**：添加/删除/上移/下移；新步骤类型按 文件部署→批量命令→重启→恢复检查 轮转，已选步骤可切换类型（切换会把该步参数重置为空，需重填）。
- **文件部署参数**：文件条目表逐行编辑（本地路径｜远端路径｜方向 上传/下载｜覆盖 覆盖/跳过）；「添加文件…」（可多选）与「添加目录…」批量生成条目行，远端路径=「远端目录前缀」框拼接条目名——该前缀框**仅是批量添加的 UI 辅助，不写入模板参数**（留空=根目录）；旧版 `files`+`remoteDirectory` 简写参数打开即归一为条目表。
- **批量命令 / 恢复检查参数**：**多行命令编辑器，一行一条命令**（空行忽略）+ 单条超时秒数（1..600，默认 10）；恢复检查复用同一面板，页顶多一条"重启后恢复检测"说明。
- **重启参数**：无额外必填参数，发送默认 `reboot` 命令，端点断开按预期成功收口（v2.10 既有语义）。
- **协议过滤**：四种步骤类型共享的协议下拉（不限/ftp/sftp/telnet/ssh，位于参数页之上），按步读写、留空=自动选端点。
- **保存闸**：点「保存」先校验（名称非空、至少一个步骤、每步参数可执行性、模板不含凭据秘密值），不通过弹中文原因并**停留对话框继续编辑**；未来版本的未知字段原样携带不丢失。
- **删除模板**：左栏「删除模板」（选中启用）弹确认（**默认「否」**，文案注明步骤数），确认后才删；删除只移除模板本身，**历史执行记录为不可变快照不受影响**。

#### 模板跨机迁移（v2.13：导出/导入模板）

一台机器调好的任务模板，存成文件带到另一台机器（如另一条产线）直接导入，免去重敲步骤参数。入口在任务中心页右栏操作按钮行：

- **导出模板**：先在左栏选中模板（未选中时按钮禁用），点击后打开保存对话框，**默认文件名 = 模板名清洗非法字符 + `.json`**（`<>:"/\|?*` 替换为下划线、首尾点/空格去除，清洗后为空回退 `task-template.json`）。写成功弹信息框显示路径；无法打开目标写入（如目录无权限）弹错误框说明原因，不做清理；写入不完整（如磁盘满）弹错误框并删除半截文件。
- **导入模板**：恒可用，点击选择 `.json` 文件即可。解码按四道校验依次执行——JSON 可解析 → 格式魔数 `deviceforge.task-template` → 版本闸（当前只认 `formatVersion=1`，**更高版本文件明确拒绝**并提示"请升级 DeviceForge 后导入"）→ 字段结构解码（含敏感凭据字段拒收）。**任一校验不过即整单拒绝、不落库**（不落半成品），拒绝原因以中文弹窗给出。
- **同名策略**：导入模板与本机既有模板同名（大小写敏感精确匹配）时弹三选「**覆盖 / 改名 / 取消**」，**默认按钮=改名**（防回车误覆盖本机模板）。覆盖=原位替换既有同名模板内容并继承其 ID 与版本号（版本以本机既有记录为准，**导入文件自带的版本号在覆盖时不生效**；历史执行记录为不可变快照，不受影响）；改名=自动追加「名称 (2)」，仍冲突则递增「(3)」「(4)」…直到空位；取消=不落库、静默收场。
- **悬空引用**：模板引用的设备档案 ID 在本机不存在时**原样保留不剥离**，导入成功框第二行提示「引用了 M 个本机不存在的设备档案，建好同端点档案后自动接上」——设备档案 ID 由端点（协议+地址）派生，在新机器上建好同端点档案后模板目标自动接上，故可"先带模板、后建档"。标签选择（tagSelectors）是松引用，导入不做存在性校验（执行期圈不到即空选）。
- **文件内容与安全**：模板文件是 UTF-8 JSON，只含模板本身（名称/描述/步骤/目标档案引用/标签）；**不含本机主键 templateId**（新模板导入时由本机生成新 ID；覆盖既有同名模板时继承其 ID，见上条同名策略），**不含任何凭据秘密值**（模板模型本就只存凭据引用，密码经 DPAPI 加密留在本机配置库、不可跨机携带）。

### 文件部署

批量上传文件到多台设备（**仅普通文件**：面板上选中文件夹条目会被传输层在触碰远端前拒绝，报「本地源文件不存在、不是普通文件或无法读取」，需先进入目录逐项勾选），支持 **FTP/FTPS** 与 **SFTP** 两种协议，界面为本地/远程双栏文件管理器（左右两栏均为统一表格视图，TC 化交互）。

1. 在设备总线添加目标设备（点 "+" 按钮）
2. 切换到「文件部署」Tab
3. 在工具栏选择协议：**FTP**（默认端口 21）或 **SFTP**（默认端口 22）——选 SFTP 时端口自动切换为 22，FTPS 选项自动禁用；选择目标设备后右侧面板自动连接并列出远程目录（设备总线**添加/删除设备**后也会自动重新连接刷新）
4. （可选）勾选 **FTPS 加密传输**（仅 FTP 协议）；FTPS 选项右侧为**连接状态点**（圆形指示灯：灰=未连接/未配置、青绿=连接成功、红=连接失败、连接中=灰闪），工具栏部署组中的「**⟳ 刷新**」按钮可手动重新连接并刷新远程列表（远程面板未连接时会提示「未连接远程，请选择设备并刷新」）。连接与远程列表加载均为**异步执行**——连接/读取慢速或断网目录时界面不会冻结，状态点灰闪表示正在连接
5. 文件浏览与导航（左右两栏操作一致）：
   - 面板顶部**路径栏上方有源选择器**：源类型下拉（**本地 / FTP / SFTP**）+ 面板级设备下拉（远程源时显示）。左侧面板默认本地，可独立切换为 FTP/SFTP 远程浏览；右侧面板与工具栏**双向联动**——在面板上切换源会同步工具栏协议/设备并自动重新连接（工具栏切换同理）
   - **双击**进入目录，双击 `..` 返回上级；选中目录后按**右方向键**进入，按**左方向键**返回上级并重新选中刚才离开的目录；面板顶部**路径栏**直接输入路径回车跳转，底部面包屑显示当前路径
   - **F2** 重命名选中项；**F5** 复制选中项到对面面板；**F6** 移动选中项到对面面板；**Tab** 切换面板焦点（快捷键提示常驻状态栏左侧）；**F4** 或**双击文件**打开预览编辑器（见下）
   - **元数据列（v2.12）**：列表在名称/大小之外显示**修改时间、权限、所有者**三列。Unix 格式 FTP 与 SFTP 可给出权限与所有者（SFTP 所有者显示 uid 数字，如 root=0）；Windows 格式 FTP 与协议拿不到的信息一律显示 `—`（Windows 本地栏的所有者也常因权限取不到而显示 `—`）；创建时间 FTP/SFTP 协议均不提供，故不设该列
   - **目录对比（v2.12，Ctrl+M）**：双栏上方「目录对比」开关按**元数据口径**（同名比大小，两侧时间都可得时再比修改时间，分钟精度）把左右目录分类着色：同名有差异=琴色淡底、仅单侧存在=同族加深一档，另一侧插入灰纹占位行对齐（显示"本地独有/远端独有"，不可选）；「仅显示差异」勾选后隐藏相同项，底部汇总条给出「差异/仅左/仅右/相同」计数。对比只读、不改动文件；任一侧目录刷新（导航/上传/删除等）自动退出对比态
   - **预览/编辑回传（v2.12，F4）**：选中文件按 F4（或双击、右键「预览/编辑」）打开内置编辑器——文本文件自动探测编码（UTF-8/GBK/UTF-16 BOM 等，可下拉手动切换重解码），编辑后「保存并上传」经**异步回传**覆盖原路径；上传前自动检查远端文件是否在你打开后被他人改动，有变化则弹出覆盖/放弃并刷新确认。**所选编码无法表示全文某些字符时**（如切到 GBK 后文本含 emoji/生僻字），保存弹出明示二选一：「用 UTF-8 保存」（编码下拉同步切换，显示与实写恒一致）或「返回编辑」（不保存）——绝不静默换码写盘（v2.13 #48）。超过 2 MB 或探测为二进制、**或行尾混用（CRLF/LF 混杂）**的文件以只读横幅提示不可编辑（前者建议下载后处理；后者为避免保存时擅自改写全文行尾，请先在别处统一行尾）；纯 CRLF 或纯 LF 文件保存时保持原行尾；全程不冻结界面，日志只记路径与字节数、；带未保存修改**关闭编辑器**时才确认"丢弃修改？"（仅关闭守脏：切换目录/刷新不打断编辑，内容保留、保存仍回传打开时所在路径）不记文件内容
   - 本地双栏的源与目标指向同一个文件时，拒绝复制和移动并保留原文件；同目录、`./` 路径别名、Windows 大小写别名及硬链接均纳入检查。F6 在目标交付后、删除源文件前再次核对；若此时两者等价，则保留文件并提示复核。
   - 右键菜单：进入 / 预览/编辑（文件） / 新建目录 / 重命名 / 删除 / 复制到对面 / 移动到对面 / 复制路径 / 刷新
   - **面板间拖拽**：把文件从一侧面板拖到另一侧即复制（方向语义：本地→远程=上传、远程→本地=下载；远程↔远程暂不支持）
   - **系统文件拖入**：从资源管理器把文件直接拖入**远程面板**即上传到当前目录（面包屑提示「上传完成」；有失败项时「上传完成，N 项失败」；拖入内容均非本地文件时提示「未检测到可上传的文件」）；拖入本地面板会提示「拖拽上传仅支持远程面板」
6. **批量部署**：先在**右侧远程面板导航到目标目录**（部署目标目录 = 右侧面板当前路径），再在左侧本地面板选中要部署的文件（文件夹条目会被传输层拒绝，见本节首段说明），点击「**▶ 部署到 N 台设备**」（N 为已选中设备数，未选中时部署到全部设备）；若左侧面板当前为远程浏览源，部署会被拦截（日志提示「左侧面板当前为远程浏览源，请切换为「本地」后再部署」）
7. 部署按**并行调度**执行（最大并发数 = 设置中的「部署并发度」，缺省 1 即逐台串行），单台失败不影响其他设备继续部署；状态栏中央实时显示「左路径 → 右路径」部署方向指示。进度区逐行显示每台设备状态（等待中/上传中），部署结束各行给出终态着色：成功（青绿）、失败（红）、已取消（灰——用户点击「取消」后未再执行到的设备均标为已取消）
8. 部署结束后工具栏右侧提供两个结果操作：
   - **⬇ 导出报告**：把本轮每台设备的结果明细导出为 **CSV**（归档/Excel）或 **HTML**（极简黑白表格，可直接打印）。原有设备、结果、失败文件、错误摘要、耗时与开始时间六列保持顺序，末尾追加 `non_atomic`（true/false）；非原子写入同时在日志告警。
   - **↻ 重试失败设备**：仅恢复上次失败设备中尚未交付的文件，目录按文件恢复，跳过已校验交付项；有已交付文件时不再次清空远端目录，无已交付文件（如首次连接失败）则仍按原选项清目录。沿用文件清单、目标目录、协议与重启选项，凭证取设备总线当前值；用户主动取消的台次不计入重试范围。普通「部署」始终执行新部署，不使用恢复记录；更换用户、协议、目标路径或文件清单后也按新部署处理。恢复记录仅在当前运行进程中有效。

#### 保存为模板（v2.14 #49-2）

单次部署跑通后，可把当前配置一键固化为可复用的任务模板：工具栏部署组「▶ 部署」旁的「**保存为模板**」按钮（objectName `deploySaveTemplateBtn`；部署进行中与「▶ 部署」同节奏禁用）。

- **前置拒绝与部署入口同源**：左侧面板为远程浏览源时提示「左侧面板当前为远程浏览源，请切换为「本地」后再保存模板」；本地文件清单为空时提示先选中文件。目标目录取右侧远程面板当前路径（为空回退根目录 `/`）。
- **字段映射**（只承载模板体系已能表达的字段，不扩模板 schema）：

| 单发配置 | 模板承载 | 说明 |
|---|---|---|
| 左面板本地选中文件 + 右面板当前目录 | deploy 步骤 `parameters.files + remoteDirectory` | 编辑器打开即归一为条目表 `items[]` |
| 协议（ftp/sftp 工具级选择） | deploy 步骤现有协议口径 | 与引擎 `parseDeployItems`/执行通道一致 |
| 设备总线勾选设备 | 模板 `deviceIds` | **未勾选=未绑定**：deviceIds 留空、编辑器明示「未绑定设备」，**不展开成「全部设备」**（区别于单发部署「未选中时部署到全部设备」的语义）；遗留胶囊中档案 ID 为空的逐个过滤 |
| 「部署后重启」勾选且已配命令 | 预填第二个 reboot 步骤 | 未勾选则只有 deploy 一步；命令留空回退默认 `reboot`（与引擎缺省同口径） |
| 部署前清空、FTPS/端口、并发度 | **不进模板** | 工具级/连接级配置；模板语义是「部署什么到哪」 |
| 文件夹条目 | **不透支** | 与单发部署同口径：传输层仅普通文件可传，目录条目在执行前即失败（不静默展开） |

- **编辑与落库**：捕获结果以预填打开任务中心同一**模板编辑器对话框**（默认占位名「单次部署模板」，请在对话框内改名），保存闸与编辑器一致（校验不过弹警告停留继续编辑）；确认后经 `TaskTemplateStore::saveUniqueByName` 落库——同名（大小写敏感全等）冲突弹三选「**覆盖 / 改名保存 / 取消**」，**默认按钮=改名**（与 v2.13 导入冲突同口径）：覆盖=继承既有模板 ID 与版本规则原位替换；改名保存=「名称 (2)」递增找空位另存新模板；取消=不落库。
- **结果**：成功记部署页日志「已保存为模板「X」，可在设备任务中心查看」；未落库时日志给出中文原因（取消/校验/存储拒绝）。

#### v2.9 传输可靠性语义

- CSV/HTML 报告在原有六列末尾追加 `non_atomic`，用于筛选需现场复核的非原子交付。

### Modbus 测试（v2.12 重构）

多 PLC 主站轮询 + 单点写入的 Modbus TCP 测试工具，页面为**左·连接清单 + 右·逐寄存器视图**双栏（沿用 WebSocket 版式族，分隔条可拖动，列宽均可拖动）。

- **目标模型**：一行 = 一个"设备档案 × 从站"轮询目标（身份 `deviceId#slaveId`），周期/寄存器段/数量逐目标独立配置（默认从站 1、保持寄存器、周期 1000ms），不再"全局段广播"
- **左·连接清单**：列为 状态｜名称（档案名称优先，无档案回退 ip:port）｜端点｜从站｜段范围｜周期｜状态/耗时（溢出时追加"跳过N"）；顶部 `[＋添加目标]` `[编辑目标]` `[删除目标]` `[暂停轮询]` `[立即读取]` 与搜索框（名称/IP 过滤，只影响视图，后台照常轮询）
- **添加目标**：下拉只列含 modbus 端点的设备；无端点的设备走"其它设备…"入口，选择即自动创建默认 502 端点并写回档案
- **编辑目标**：双击清单行或点「编辑目标」打开编辑弹窗——从站号 1..247、寄存器段四选一、起始地址 0..65535、数量按段动态钳上限（寄存器 125 / 位 2000）、周期 500..60000ms、是否启用；保存后写回 `modbus.target` 记录，轮询在跑时自动按新参数重启调度。**把从站号改成新号并保存 = 为该设备追加第二从站目标**（原目标保留，不需要可删除）
- **删除目标**：选中行点「删除目标」，从记录中移除该从站；删除设备的全部目标后保留**空记录**，旧配置行不会复活
- **端口编辑**：双击清单端点列就地改端口，经设备档案（`saveReplacing`）写回，同设备其余从站行同步刷新；重启后档案生效、旧配置行不复活
- **右·寄存器视图**：选中目标后逐寄存器一行，列为 地址｜十进制｜十六进制｜变化｜更新时刻；地址按 **4xxxx 编址**显示（Holding=40001 起、Input=30001 起、Discrete=10001 起、Coil=0 基 5 位零填充）；`[十六进制]` 开关全局切换十/十六进制呈现；数值变化的行以 ↑/↓ 标记
- **写入**：双击数值行打开写弹窗——**地址 0..65535 自由输入**（双击行的地址仅作预填便利，不受轮询段限制），值域按段钳制（线圈只填 0/1，寄存器 0..65535）；确认后弹出确认框（**默认按钮为「取消」**，需主动点「写入」）；寄存器写走 0x06，线圈走 0x05；写入经调度器插该连接队首优先执行，同端点读写串行不互踩；待发队列（每连接上限 8）已满时写请求被拒绝并提示"操作过多，请稍后"，绝不静默丢弃
- **状态灯**：OK 石墨 / 异常红 / **退避黄**（连接故障进入重试退避等待）/ 停用灰；错误摘要进状态列（截断 + 悬停全文）
- **轮询调度**：250ms 单节拍驱动；同端点多从站共用一条连接轮流轮询，不同主机并行；慢 PLC 或未回请求不堆叠——队列溢出丢弃的是最旧轮询项并计数（清单详情列"跳过N"）；连接故障自动**指数退避**（1s→2s→5s→10s→30s 封顶），恢复后自动回到正常轮询
- **暂停/恢复**：「暂停轮询」停止一切读写派发（队列与退避清零），「恢复轮询」按当前清单整组重启；「立即读取」对选中目标补发一次读取
- 数据源为设备档案（modbus 端点），首次进入自动迁移旧版从站配置（`modbus.slave`）为轮询目标，迁移无感、失败不崩

### WebSocket 通信

内建 Server 和 Client 双模式，页面为**左控制台 + 右消息事件流**双栏（v2.12 重构，窗口拉伸比例自适应不乱版，分隔条可拖动）。

- **模式切换**：Server / Client 分段按钮；配置区随模式只显当前所需字段
- **Server 模式**：绑定地址（默认 127.0.0.1）、端口（默认 9001）、WSS 开关（内置自签名测试证书）、Token（默认掩码显示，可点「显示」查看；最长 256 字符，超出会被输入框截断且启动时拒绝并提示，不生效）
- **Client 模式**：服务器 URL（ws:// 或 wss://）、信任自签名证书（仅测试）
- **运行守卫**：运行中禁用绑定地址/端口/WSS/Token/服务器 URL/信任证书等连接参数输入，需修改请先停止再重新启动（防止运行中改动参数造成与实际监听/连接配置不一致的错觉）
- **运行状态卡**：运行指示灯、实际监听地址/连接目标；Server 模式实时列出在线客户端，Client 模式列出已订阅主题
- **消息事件流**：时间｜方向（收/发）｜主题｜对端｜字节｜内容预览六列，列宽可拖动；「对端」列显示消息来源——Server 模式「收」行为客户端地址（IP:端口），Server 模式「发」行（服务端向订阅者下发）对端固定记「订阅者」，Client 模式恒为 `server`；上限 2000 行，超出丢弃时提示"已丢弃 N 行"（计数仅统计本会话：重新启动或清除事件流后归零，单点停止不归零，不跨重启累计）；悬停预览单元格查看正文全文；「自动滚动」可关闭，「清除」一键清空
- **事件过滤（v2.14）**：事件流工具条提供方向过滤下拉（全部/收/发）与主题过滤输入框（大小写不敏感子串匹配），在收/发密集或主题多时快速聚焦关心的行。过滤是**展示层隐藏**——所有事件仍全量入表，2000 行上限与"已丢弃 N 行"计数语义不受过滤影响（不存在"过滤后不再接收"）；新到达的事件按当前过滤条件即时隐藏；「清除」始终清空全表并归零计数、与当前过滤条件无关，且**过滤条件本身保留**，清除后新推入的事件仍按它继续过滤
- 支持 SUBSCRIBE/PUBLISH 主题订阅；正文只进本页面事件流，综合日志仅记方向与字节数（脱敏约束）
- 启动时自动恢复上次使用的端点配置（端口/地址/URL/WSS/信任证书；**Token 出于安全不保存、不回填**，每次需重新输入）

### 网络调试（中继 + 录制回放 + 组播抓收/转发）

在不影响生产数据流运行的前提下，串接在数据生产者与真实消费者之间，原样双向转发流量并旁路抓包，还可录制流量供日后回放。组播（Multicast）模式下，工具以**额外订阅者**身份加入组播组抓收数据（零影响），可录制、可**实时转发**、可回灌。

**中继抓包：**

1. 切换到「网络调试」Tab
2. 选择协议（TCP / UDP / **Multicast**）——选择后界面自动联动：Multicast 模式下隐藏「监听地址/端口」（无监听概念），目标标签变为「**组播组地址**」
3. TCP/UDP：设置**监听地址**和端口（工具在此等待生产者连接）+ **上游地址**和端口（真实消费者）
4. **Multicast：设置组播组地址和端口**（如 `239.1.2.3:5000`），并**选择网卡**（多网卡机器必须选对网卡，否则收不到组播数据）
5. （可选）勾选「录制到文件」并选择 `.nrec` 保存路径
6. （可选，仅 Multicast）勾选「**实时转发到**」并填写目标地址/端口：
   - **单播目标（M→U）**：把抓到的组播数据实时转发给指定单播消费者（如不在组播域的仿真设备）
   - **组播目标（M→M）**：转发到另一组播组——启动前会二次确认（请确保目标组没有真实源在发送，否则接收方收到混叠数据；避免 A→B→A 转发环路）
7. 点击「▶ 启动」
8. 让数据生产者改为连接工具的监听地址；工具会把流量原封不动转发到上游消费者（TCP/UDP）
9. 在「十六进制视图」实时查看上/下行数据（上行青绿、下行琥珀），「会话列表」查看各连接字节数
10. 点击「⬇ 导出」保存当前 Hex 视图快照，或「■ 停止」结束并保存录制

**回放：**

1. 先「■ 停止」中继（回放与中继互斥）
2. 在「回放」区选择之前录制的 `.nrec` 文件
3. 「消费者」地址端口：**TCP/UDP 必填**（回放数据发往此处，模拟生产者）；**组播文件留空 = 回灌录制时的原组播组**，填写则覆盖为单播发送
4. 选择速率（原速 = 还原原始时间间隔 / 尽快）
5. 点击「▶ 回放」，进度条显示已回放条数；可「⏸ 暂停」/「■ 停止」

> **说明**：回放只重放录制中的**上行**数据（生产者→消费者方向）到消费者；下行数据保留在文件中但当前不回放。组播回放默认灌回录制时的原组播组地址/端口，可在回放区覆盖；回放前依据 `.nrec` 文件头判断协议并提示「确认真实源已离线，避免混叠」。
>
> **安全提示**：监听地址默认为 `127.0.0.1`；填写非回环地址会输出安全警告（中继无客户端鉴权，暴露到网络需环境可信）。`.nrec` 录制与导出文件可能含明文凭证/敏感数据，导出前会二次确认，文件权限限制为仅所有者可读写。

### OPC UA 客户端

连接 OPC UA 服务器，读/写数据点并订阅数据变化（基于 open62541 v1.5.5）。

1. 切换到「OPC UA 客户端」Tab
2. 在 Endpoint 填写服务器地址，如 `opc.tcp://192.168.1.10:4840`
3. 安全策略选「None」、认证选「匿名」（首期支持），点击「连接」，状态灯变为 ●已连接
4. **浏览地址空间**：点击浏览，表格列出服务器 Objects 节点（5 列：# / 显示名 / NodeId / 数据类型 / 节点类）
   - 顶栏搜索框即时过滤，统计「共 N 项 · 匹配 M」
   - 节点类色块：Variable（青绿）/ Object（石蓝）/ Folder（深石）/ Method（琴色）
   - 数据类型显示友好名（`i=24 → Int32`，`i=12 → String` 等）
   - 双击行把 NodeId 填入右侧读/写面板
5. **读/写**：在 NodeId 填写节点标识（如 `ns=2;i=2255`），点「读」查看当前值，或填入新值点「写」
6. **删除点位**：批量表/订阅表每行末尾有 × 按钮，点击删除该行（按几何反查行号，避免索引漂移）
7. **订阅**：把要监控的节点加入订阅表，点「订阅」，节点值变化时最新值+时间戳实时刷新；点「停止」结束订阅

> **NodeId 格式**：`ns=<命名空间>;i=<整型>`（整型编码）或 `ns=<命名空间>;s=<字符串>`（字符串编码）。
>
> **首期限制**：仅 None 安全策略 + 匿名认证，无加密。安全策略加密（Basic256Sha256）、用户名/证书认证、Method 调用为后续版本计划。
>
> **非规范服务端兼容**：某些设备（GetEndpoints 返回的 EndpointUrl 与连接 URL 不一致，如 `opc.tcp://0.0.0.0:4840`）会触发 open62541 内部端点 UAF；open62541.c 中的 DeviceForge patch 在 ActivateSession 阶段对 `utp->policyId` 做 `UA_String_copy` 深拷贝，匿名认证下回退为空 policyId，使连接能够完成（UaExpert 同样容忍此类服务端）。

## 安全功能

- **FTPS 加密**：文件部署 Tab 中勾选
- **Telnet 警告**：首次使用时弹出明文传输风险提示
- **WebSocket 认证**：可配置 Token 认证（URL 参数 `?token=xxx`）
- **网络中继**：监听地址默认 127.0.0.1，非回环绑定输出安全警告；录制/导出文件二次确认 + 仅所有者可读写
- **密码安全擦除**：断开连接后自动擦除内存中的密码
