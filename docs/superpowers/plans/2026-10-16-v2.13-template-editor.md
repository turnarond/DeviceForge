# v2.13 任务模板编辑器（#54）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 任务中心内新建/编辑/删除任务模板，产品内可产出第一份模板（兑现 v2.11 规格能力承诺，堵 #54）。

**Architecture:** 独立对话框 `TaskTemplateEditorDialog`（纯表单 ↔ `TaskTemplate` 转换 + `validate()/collect()` 可直调测试缝）；`TaskTemplateStore::remove` 补存储腿；`TaskCenterWidget` 只做按钮接线/双击入口/落库编排。deploy 简写参数在打开时一次性归一为 `items[]` 规范形态。

**Tech Stack:** Qt 6.11.1（CI 上限 6.9.2）、C++17、QtTest/CTest（现有 46 目标，本计划不新增目标）。

**Spec:** `docs/superpowers/specs/2026-10-16-v2.13-template-editor-design.md`（docs/v2.13-template-editor-spec@bffd282）

**载体:** 自 main@929b3bb 新建分支 `feature/v2.13-template-editor`，worktree `.worktrees/v213-editor`，构建目录 `build_ed/`（先补 .gitignore）。

## Global Constraints

- 全中文注释与 UI 文案；Qt API ≤6.9.2；禁 QSettings；依赖方向 UI→业务。
- TDD 红-绿；一个 Task 一个提交；提交前全量构建 0 error + 全量 ctest 46/46。
- 引擎参数契约逐字一致（规格 §2 表）：`items[].localPath/remotePath/direction(upload|download)/overwrite(overwrite|skip)`、`commands[]`、`timeoutSec`（1-600，默认 10）、`protocol`（空=不限/ftp/sftp/telnet/ssh）。
- `unknownFields` 与未触及字段对话框进出全量携带；悬空 deviceIds 显示"(本机无档案)"且默认保留、不强制剥离。
- 删除确认框默认按钮=「否」；文案带模板名与步骤数；执行历史不受影响（快照语义）。
- 校验文案与引擎 parse 同口径（例："步骤 %1（文件部署）存在缺少 localPath/remotePath 的条目"）。
- 测试目标源表变更点：`CMakeLists.txt` 主 app（:214 区）与 `tests/CMakeLists.txt` tst_task_center_widget（:723 区）都要加 `TaskTemplateEditorDialog.cpp`。
