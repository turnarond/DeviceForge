色彩纪律核对：琴色只出现在信号态——对比差异行、主按钮、选中态、可点击汇总数；目录结构/表头/网格线全部石墨（#252A33/#333B48/#1A1F28）。差异淡底用同族 alpha 分层（diff 0.10 / only 0.18），不用第二色相，避免与"绿=相同"旧着色打架——旧自动绿/黄在对比态被接管替换，非对比态原样保留。占位行比表格底色更深一档（#080B10），配虚点纹理表明"此处无实体"。QSS 实现：行色全部经 model Qt::BackgroundRole brush，不进 QSS 选择器（QSS 无行级伪类）；亮深色两套主题各挂一组常量，落 ThemeTokens 一处定义。
