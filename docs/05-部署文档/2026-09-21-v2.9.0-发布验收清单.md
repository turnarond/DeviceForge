## 8. 发布门槛

当前已确认 VS Release 构建成功，且现有局域网示例截图可公开；自动化测试、版本校验和其余发布素材仍按下表逐项闭环。

> DPAPI 证据：实际 Visual Studio 用户环境中 `tst_dpapi_crypto` 为 4 passed、0 failed。代理沙箱使用了与 `USERPROFILE` 不匹配的临时用户 SID，不能作为发布环境测试结论。

只有以下条件全部满足，才创建 `v2.9.0` Tag 并发布 GitHub Release：

1. Release 构建通过；
2. 全量 CTest 通过；
3. 版本校验通过；
4. UI 冒烟通过；
5. FTP/FTPS/SFTP 至少各完成一次现场验收；
6. 双栏上传、下载和批量部署均有可复核结果；
7. 发布包可在干净 Windows 环境启动；
8. 发布文章和截图完成脱敏检查。
