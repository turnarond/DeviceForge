# DeviceForge v2.9.0

DeviceForge v2.9 将工业设备部署工具从“能连接、能上传”推进到“可以长期驻现场工作”。本版本统一了双栏上传/下载、批量部署和本地文件操作的可靠性语义，并完善了面向 FTP/FTPS/SFTP 的双栏文件工作区。

## 主要变化

### 统一可靠传输闭环

- 双栏上传、双栏下载、本地复制/移动和批量部署统一接入 `TransferScheduler → TransferExecutor → ITransferChannel`。
- 增加瞬时错误有限重试、SHA-256 校验、临时文件提交和失败恢复跳过。
- 支持项目级取消，并保留文件级失败明细。
- 对非原子交付场景显示明确告警。

### 双栏现场工作区

- 本地、FTP/FTPS、SFTP 使用统一文件面板。
- 支持方向键导航：上下选择、右键进入、左键返回。
- 返回父目录后自动重新选中刚才进入的目录，连续键盘操作不中断。
- 目录加载异步执行，过期结果不会覆盖新路径。
- FTP CRLF 列表响应不会把行尾回车解析为目录名。

### 批量部署

- 支持可配置并发度 1—8。
- 每台设备独立显示进度和终态。
- 单台设备失败不影响其他设备。
- 支持失败设备一键重试。
- 支持 CSV/HTML 部署报告。

### 现场体验

- 首窗口优先，非首屏能力按需初始化。
- 工作区保留设备、协议、路径和任务上下文。
- 暗色/亮色双主题继续保持一致。

## 升级说明

- v2.9 保持 FTP/FTPS/SFTP 现有配置语义。
- 建议升级前备份 `%APPDATA%/DeviceForge/config.db`。
- 现场部署前请先在测试设备上确认目标目录、权限和覆盖策略。
- SCP、跨平台 GUI 和插件化 ToolHost 不属于本版本交付范围。

## 已知边界

- 传输中断后的恢复以文件级重新执行为主，不承诺字节级断点续传。
- 具体 FTP 服务器对 LIST 格式、权限和目录语义的差异仍可能影响兼容性。
- Windows Release 包需要匹配的 VC++ 运行库。
