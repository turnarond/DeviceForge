# DeviceForge v2.9.1

v2.9.1 是 v2.9.0 的稳定性补丁版本，重点修复 FTP 批量部署在原子提交阶段的瞬时失败。

## 修复内容

- FTP 上传、重命名、删除和建目录等 QUOTE 操作统一缓冲服务器响应，避免 GUI 进程默认标准输出导致 `CURLE_WRITE_ERROR`。
- 将瞬时 FTP 响应写入错误纳入自动重连和重试策略。
- 保持认证失败、权限不足和路径错误不重试，避免无效重复操作。

## 验证结果

- `tst_transfer_types`：8/8 通过。
- 传输与部署相关测试：6/6 通过。
- 现场三台设备批量部署复测稳定。

## 升级说明

v2.9.1 兼容 v2.9.0 的配置和部署路径，建议直接替换整个便携包目录，不要混用旧版 Qt DLL 或插件。
